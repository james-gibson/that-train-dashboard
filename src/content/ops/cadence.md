# The cadence

- **Weekly.** The team reviews the open studies, confirms the run records, and updates the stage on
  each page. The dashboard's last-review date comes from this.
- **Monthly.** A recut: every running study gets its scenario re-run on the current version. A study
  that no longer reproduces is a finding about the version, not a failure of the team.
- **On trigger.** A study whose conclusion changes gets reviewed before the next scheduled slot. The
  trigger is a changed result, not a changed opinion.

## Why the cadence is written down

Because "we will keep it current" is not a schedule, and a dashboard without one is a museum. The
review date on the home page is the only promise this site makes about freshness, and it is a
promise about attention, not about the software.
