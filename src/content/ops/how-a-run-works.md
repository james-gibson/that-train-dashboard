# How a run works

1. **Scenario.** A saved OpenTTD scenario plus a seed and a written question. No question, no run.
2. **Run.** The coordinator runs it and records the wall-clock time and the game version.
3. **Capture.** The screenshots and the exported figures go into the run record, named by date and
   arm.
4. **Review.** The analyst reads it, the skeptic writes the counter-case, and the archivist checks
   the provenance before anything is published.
5. **Write.** The study page gets the finding, or the honest "inconclusive".

## The step that is not negotiable

Step 4. A run that skips review is a screenshot with a story attached. The cost of the review is an
hour; the cost of skipping it is a finding nobody can defend later, which is worse than no finding.
