# Sources and provenance

Every study page names the artefacts it depends on. A reader who wants to check a finding needs four
things, and all four are recorded:

1. the **OpenTTD version** the run used;
2. the **map and seed**;
3. the **scenario file**, by name and date;
4. the **commit** of this dashboard at the time the finding was written.

If one is missing, the finding is labelled inconclusive rather than softened. That rule is cheaper
to keep than to explain later.

## The parent

This site is a child seed of [le.gume](https://james-gibson.github.io/le.gume/): the same content
model, the same derived navigation, the same build gate. It is a different team, a different
question and a different design system, which is the point — the pattern is the reusable part, not
the components.
