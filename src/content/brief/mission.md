# What this dashboard is for

We study economic questions the cheap way: we build the mechanism in OpenTTD, run it, and record
what the simulation did. The dashboard is the shared record — one page per study, one page per
operational rule, and nothing that only exists in someone's head.

It is not a forecasting tool and it is not a game review. OpenTTD is a toy economy with clean
arithmetic and no politics, which makes it useful for one thing: **seeing whether a mechanism
behaves the way the argument says it will** before anyone spends money on the argument.

## The team

Five roles, each with a page in [the team brief](/brief/team). They are adapted from an incident
warroom, because a warroom and a research review have the same failure: everyone agrees, nobody
checks.

## The rule

Every claim on this site is attached to a run. A claim without a run is a hypothesis and is labelled
as one. A run without a recorded seed, version and scenario is not a run.
